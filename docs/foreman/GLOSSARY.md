# 📒 Foreman's Glossary — terms taught on the shop floor

One entry per real CS term, with the day it earned its place.

- **User Acceptance Testing (UAT)** — validation performed by the
  stakeholder using the real system; the owner's QA passes ARE the
  acceptance record. (2026-07-25)
- **Verification vs Validation** — "built right" (test suite) vs
  "right product" (owner's hands). Two independent evidence layers.
  (2026-07-25)
- **Reference architecture** — the industry's proven blueprint for a
  problem class; Sentinel matches the local-first desktop shape
  (SQLite core, GUI shell, no server). (2026-07-25)
- **Eisenhower matrix** — urgency×importance triage: Do / Schedule /
  Delegate / Defer. Applied to the punch list in TOPICS.md.
  (2026-07-25)
- **Defect classification & trend analysis (IEEE 1044)** — classify
  every defect, tally classes, alarm on recurrence: the red-plum rule.
  (2026-07-25)
- **WORM storage** — Write Once Read Many; why burned discs resist
  ransomware and synced mistakes. 3-2-1 backup rule: 3 copies, 2 media
  kinds, 1 offsite. (2026-07-25)
- **Design-by-contract vs heuristic** — a registered hook is a promise;
  a tree search is a guess. Second field miss converts guess → promise
  (shop-defect-laws, Law 4). (2026-07-25)
- **exportselection** — Tk default making every listbox selection one
  mutually-exclusive token; the stolen-selection defect class.
  (2026-07-25)
